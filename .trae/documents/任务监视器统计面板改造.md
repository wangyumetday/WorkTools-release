# PCP 任务监视器：隐藏开始/暂停 + 可折叠数据统计面板

## Context（为什么改）

右侧任务监视器：1）「开始/暂停」按钮不再需要（仅隐藏 UI，实现保留）；2）「任务队列」区扩展为可折叠的「数据统计面板」——面板内上块=任务队列，下块=统计块，展示 6 个**数量**指标（用户确认不要比率），每项 hover 提示含义，随在跑任务刷新（复用来就已低频的 task:state 推送，不做轮询，不拖累任务效率）。

## 统计指标定义（全部为跨任务聚合计数，来源=各任务 result.summary）

| 指标名 | 计算 | 提示文案 |
|---|---|---|
| 胜出数量 | Σ summary.quoteWon | 能比赢的官网对比单元数（我方底价不高于最低可比报价） |
| 胜出未显示 | Σ summary.**quoteWonHidden**（新增字段） | 比赢但其命中的报价是「我方投放且未在携程外显」的数量 |
| 投放总数 | Σ summary.quoteTotal | 携程返回的全部报价条目数（含我方与其它投放） |
| 我方投放 | Σ summary.quoteOwn | 携程查到的属于我方投放的报价条目数 |
| 独占数量 | Σ summary.quoteUnmatched | 我们锦绣数据存在、但携程无人投放（未匹配）的官网数据单元数 |
| 比输数量 | Σ summary.quoteLost | 匹配到携程报价但全部低于我方底价的官网对比单元数 |

面板折叠：默认展开；折叠后只留标题条（队列与统计都收进面板），单一滚动链不破坏（统计块固定于列表底部，不新增滚动容器）。

## 实施步骤

### 1. adapter.js 新增 summary.quoteWonHidden（electron/features/pcp/platforms/trip/adapter.js mergeResult，summary 定义 L1069-1088 附近）

- 统计口径：对比单元的命中报价是我方投放（isOwn）且未外显（showState !== 1）且该单元胜出：
  - 主行参与开启：`item._outcome === 'won'` 且 `item._hitQuote` 的 isOwn && showState!==1 → +1；
  - 主行参与关闭：`acai['携程底价'] != null`（命中）且 `acai._hitQuote` 同上 → +1。
- `mergeResult` 已持有 `forData`（originalData.dateValue 的 item，含 _hitQuote 引用）与 `mainRowEnabled`，就地计算写入 `summary.quoteWonHidden = n`；注释写明口径。

### 2. TaskMonitor.vue（src/features/pcp/components/TaskMonitor.vue）

- 「开始/暂停」块（模板 L221-225）：加 `v-if="false"` + 注释「仅隐藏界面（2026-09-23），实现保留」，CSS L93-97 保留。
- `.tm-bottom` 改为可折叠面板：
  - 面板头：折叠箭头（▶/▼）+ 标题「任务队列 · 数据统计」；`collapsed = ref(false)`；
  - 面板体（collapsed 时 v-show 隐藏）：
    - 上块：现有 `.tmb-h`（任务列表标题+并发控制）+ `<TaskList />`（L228-249 原样）；
    - 下块：新增 `.tm-stats` 统计块——6 个指标 chip（`v-for` 定义表渲染，label+数值+`:title` 提示；数值为 0 时显示 0；无任何任务时也可展示 0/—）。
- 统计计算：TaskMonitor 内 `computed panelStats`——遍历 `store.tasks` 累加 `t.result?.summary` 六个字段（O(n×6)，800 任务量级无压力；summary 只在任务 merge 完成时变化，天然低频，无需额外节流）。
- 样式：终端极简风；chip 白/灰文字、分隔线，信息 hover 用原生 title（符合项目最小染色约定）；统计块不设独立 overflow。

2. `npm run build` 三端通过。
3. 界面手测：开始/暂停块不可见；面板可折叠；跑任务时统计随 task:state 更新（任务完成即变），hover 有提示；面板折叠后列表无残留双滚动。

## 边界与风险

- 只隐藏 UI：开始/暂停实现（store actions）与其它引用不动，后续需要时去掉 v-if 即恢复。
- quoteWonHidden 属新增口径，不进任何导出文件、不影响政策/底价检查（只服务面板显示）。
- 统计面板默认展开；刷新不引入定时器/轮询，零效率影响。
