1介绍
为了提高供应商在携程网的政策投放效率，满足其业务需求，由携程机票研发部门开发了一套供应商运价维护API，

4
从模块维度分为公布运价、私有单程运价、私有往返运价和低价看板4个模块，从功能维度分为新增、修改、删除、查询和调
价5个接口。
1.1接入流程
生产环境已有手工投放政策权限的帐号可直接使用,无需额外申请。
测试环境需要通知对口业务联系携程供应商支持组申请帐号。
1.2服务访问
• 支持http或https访问，其中https协议，访问前需要预装CA证书或在调用端的程序中设置信任任何证书，否则无法正常访问。
• 接口URL拼接规则：各环境服务URL+接口名
例：测试环境服务公布运价新增接口URL:https://intlresource-exchdata.fat.ctripqa.com/api/pubFareAdd
其中 https://intlresource-exchdata.fat.ctripqa.com/api/ 为对应环境服务URL, pubFareAdd为对应接口名

1.3约定
服务的调用方（供应商）和提供方（携程）在服务过程中，需要遵循如下约定：
• 请求、响应报文字符编码为UTF-8
• 请求、响应报文的序列化方式为Json+Gzip
• 调用方负责请求报文压缩和响应报文解压缩，并确保Http Request Header中包含如下信息
• Content-Type=application/json;charset=UTF-8

5
• Content-Transfer-Encoding=gzip
• Transfer-Encoding=chunked
• Accept-Encoding=gzip
• 提供方负责请求报文解压缩和响应报文压缩，并确保Http Response Header中包含如下信息
• Content-Type=application/json;charset=UTF-8
• Content-Encoding=gzip
• Transfer-Encoding=chunked
1.4请求处理流程
!avatar
1. 客户端构建请求报文
2. gzip压缩请求
3. 发送请求
4. 服务端接收请求并gzip解压缩请求
5. 处理请求构建响应报文
6. gzip压缩响应
7. 返回至客户端
8. 客户端接收并解压缩响应

public class OpenAPIExample {
    private final Log log = LogFactory.getLog(getClass());

7
    // Connection establishment timeout time 3 seconds unit milliseconds
    private static final int CONNECT_TIMEOUT = 3000;
    // Socket timeout 25 seconds unit milliseconds
    private static final int SOCKET_TIMEOUT = 25000;
    /*
     * CloseableHttpClient Thread safe
     * reference httpComponents-client-ga/tutorial 1.2.1. HttpClient thread safety
     * HttpClient implementations are expected to be thread safe. It is recommended that the same instance
     * of this class is reused for multiple request executions.
     */
    private CloseableHttpClient httpClient;
    private CloseableHttpClient getHttpClient() throws KeyStoreException, NoSuchAlgorithmException,
            KeyManagementException {
        if (null != httpClient) {
            return httpClient;
        }
        RequestConfig reqConfig = RequestConfig.custom()
                .setConnectTimeout(CONNECT_TIMEOUT)
                .setSocketTimeout(SOCKET_TIMEOUT)
                /*
                 * ContentCompressionEnabled set true , http Request add header Accept-Encoding:gzip,deflate 
                 */
                .setContentCompressionEnabled(true).build();
        SSLContext sslCtx = SSLContextBuilder.create().loadTrustMaterial(null, (x, s) -> {
            return true;
        }).build();
        SSLConnectionSocketFactory factory = new SSLConnectionSocketFactory(sslCtx, NoopHostnameVerifier.INSTANCE);
        List<Header> defaultHeaderList = new ArrayList<>();
        // default request header
        defaultHeaderList.add(new BasicHeader("Content-Type", "application/json;charset=UTF-8"));
        HttpClientBuilder builder = HttpClients.custom()
                .setDefaultRequestConfig(reqConfig)
                .setDefaultHeaders(defaultHeaderList)
                .setSSLSocketFactory(factory);
        synchronized (OpenAPIExample.class) {
            if (httpClient == null) {
                httpClient = builder.build();
            }
        }
        return httpClient;
    }
    public void publicFareAdd() throws Exception {
        CloseableHttpClient httpClient = getHttpClient();
        HttpPost httpPost = new HttpPost("Interface Url");
        StringEntity requestEntity = new StringEntity("jsonData","UTF-8");
        /*
         * using GzipCompressingEntity
         */
        httpPost.setEntity(new GzipCompressingEntity(requestEntity));
        try (CloseableHttpResponse response = httpClient.execute(httpPost)) {
            HttpEntity responseEntity = response.getEntity();
            int statusCode = response.getStatusLine().getStatusCode();
            if (statusCode == HttpStatus.SC_OK) {
                log.info("request success response content:" + EntityUtils.toString(responseEntity));
            } else {
                log.info("request fail response content:" + EntityUtils.toString(responseEntity));
            }
        } catch (ParseException | IOException e) {
            log.error("request execute occur exception", e);
        } finally {
            releaseClient();
        }
    }
    private void releaseClient() {
        try {
            httpClient.close();
        } catch (Exception ignore) {
        }
    }
}

2.运价接口说明
公布运价、私有单程运价和私有往返运价3个模块各接口(新增/修改/删除/查询/调价)的处理逻辑和限制是一致，因此下文在介绍
时没有区分模块。部分接口的请求/响应报文模块间会有差异，下文会分别介绍。
低价看板查询可直接接生产环境，数据更准确
2.1限制
• 同一账号每天新增运价数量上限为50W（可以找业务申请放大每天新增数据数量）
• 每次请求间隔不低于20秒，高于这个频率，携程OPS可能会认为是恶意攻击，封锁IP，导致API无法正常使用
• 新增/修改/删除/调价接口

8
• 请求报文中的Seq字段必填，起始值从1开始，不能重复
• 请求中运价数量上限为5W，超出上限时，接口调用会失败，给予错误提示
• 查询接口返回运价数量上限为1W,超出时将截取1W条返回
• 低价看板查询为单条可并发请求，每分钟限制210条

分为请求头(RequestHeader)和请求体(RequestBody)两部分，请求头各接口相同，请求体各接口不同，具体见各接口说明。

2.5删除
公布运价、私有单程运价，私有往返运价处理逻辑相同：
• 删除接口按指定条件删除匹配运价记录，支持fareIDList/externalIDList/deleteFareConditionList/deleteAllType作为条件，
其中fareIDList/externalIDList/deleteFareConditionList为单选，同时指定多个条件时接口将调用失败，并给予错误提示，
deleteAllType支持与另外3个条件的其中1个进行组合
• 当条件字段是fareIDList或externalIDList时，list长度上限为5W，超出将调用失败，给予错误提示
• 当条件字段是deleteFareConditionList时，owner与policyID为and关系，list长度上限为5，超出将调用失败，给予错误提示
• deleteAllType为true时表示删除手工录入，Excel导入以及API创建的数据，默认为false仅删除API创建的数据
• fareIDList/externalIDList/deleteFareConditionList三种条件至少指定一个
删除上限为1W条,超出限制时接口将调用失败，并给予错误提示

2.8调价
公布运价、私有单程运价，私有往返运价处理逻辑相同：
• fareID和externalID字段至少其中一个有值，否则将被忽略，给予错误提示
• commition不为空且能够为正确转换为decimal数字类型时，profit不为空，调整运价的Commition 与
Profit,每条运价有不同的返点跟留钱，否则将忽略这条记录，
给予错误提示
• 调价逻辑为在原有返点，留钱的基础上进行相加或者相减，即原为a值，传递b值（正负都可）。调价后为：a = a+b

3.CSD航线策略接口说明
提供CSD票台(非kwp)航线策略模块(新增/修改/删除/查询)接口。
3.1限制
• 新增/修改/删除 每次请求间隔不低于20秒，高于这个频率，携程OPS可能会认为是恶意攻击，封锁IP，导致API无法正常使用
• 查询功能目前为分页查询，单页最大2000，每10s限制5次查询
• 新增接口支持批量，单次新增不超过500条
• 删除接口支持批量，单次删除不超过2000条
